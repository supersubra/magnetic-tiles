# Magnetic Tile Builder

A step-by-step guide that helps young kids build 3D models with magnetic tiles. Works on phones and tablets, offline, with no install.

**Play it:** https://supersubra.github.io/magnetic-tiles/

1. Enter how many tiles you have (squares, triangles, corner triangles, tall triangles, wheels).
2. Pick a size: Small, Medium or Big.
3. Pick one of 36 builds (12 per size: 4 animals and 8 other things). They open three at a time: finish all three to open the next three.
4. See which tiles the build needs.
5. Follow the animated steps — swipe or tap the arrows; each step is read aloud.
6. Celebrate!

Everything is in a single file, `index.html`, with no dependencies.
